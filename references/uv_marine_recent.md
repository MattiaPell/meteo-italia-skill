# UV, Mare e Storico Recente — Migrato su MCP

⚠️ **SPOSTATO SU MCP SERVER**:
Le informazioni di questo file sono state completamente migrate nel server MCP per ottimizzare la context window dell'agente.

- **Usa i tool MCP**:
  - `open_meteo_marine` per ottenere le previsioni delle onde, swell, periodo e temperatura superficiale del mare (SST).
  - `meteo_bioclimatic_indices` per ottenere gli indici bioclimatici di comfort (Heat Index/Afa, Wind Chill, Temperatura a Bulbo Umido, Notti Tropicali, bilancio idrico a 7gg).
  - `meteo_reference_guidelines` (categoria: `marine`) per consultare la scala Douglas (Wind Sea e Swell), la scala Beaufort del vento, le soglie SST, la classificazione della visibilità, la matrice del rischio mareggiate per settore costiero (Traversia) e il bollettino ondate di calore del Ministero della Salute.
